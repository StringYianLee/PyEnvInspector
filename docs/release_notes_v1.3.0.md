# PyEnv Inspector v1.3.0

聚焦「环境修复闭环」与「界面体验」的一次更新。

## 新增功能

- **指定解释器 + 一键修复冲突**：诊断页新增「目标解释器」下拉，可对任意已发现的环境
  单独诊断；诊断完成后自动生成修复计划（对每个被多个包约束的依赖，合并全部版本约束），
  点击「一键修复全部冲突」即在该环境批量执行 pip 安装。
  单个包失败不会中断其余修复，结束后汇总成功/失败明细；修复完成自动重新采集并刷新诊断。
- **明暗主题实时切换**：侧边栏「主题」按钮即时切换，**无需重启**。切换时会重建界面控件树
  以让所有内联样式与依赖图配色一并更新，当前环境数据自动恢复。
- **「关于」面板（属性栏）**：查看软件版本、运行环境（Python / 系统 / 运行方式 / 数据目录 /
  日志路径）、以及**完整版本更新内容**（内置变更日志，离线可看）；同时显示更新检查结果。

## 修复与改进

- **深色模式文字对比度**：正文、次级文字、弱化文字整体提亮（`#f2f5fa` / `#b8c2d4` / `#8b95a8`），
  主色与状态色改用更亮的深色主题色值；对话框（关于 / 消息框）补齐背景与文字样式，
  修复此前深色下标题不可读的问题。新增自动化对比度断言（正文对比度 ≥ 7:1）。
- 管理页操作日志面板改为跟随主题配色，深色下不再出现浅底白字。
- 修复诊断页在非当前环境下执行修复后不会刷新的问题（修复后自动重采并更新报告）。

## 兼容性

- 配置与缓存路径不变；从 1.2.0 升级会保留设置与快照缓存。
- 命令行接口不变（`python main.py --cli …`）。

## 安装

下载 `PyEnvInspector-1.3.0.msi` 双击安装（需要管理员权限），从 1.2.x 升级自动换装。
