## PyEnv Inspector v1.1.2

### 新增功能

- **添加到用户 Path 环境变量**：解释器安装页新增勾选项，新装的 `python.exe` 与 `Scripts` 目录自动追加到用户级 Path（写入 HKCU\Environment 并广播变更，新开终端立即生效，无需注销）；删除解释器时自动从 Path 移除
- **自定义安装路径**：支持将解释器安装到任意本机空目录（默认仍为 `~/PyEnvInspector/runtimes/py-<版本>`），带路径校验（防误覆盖、防指向文件、防重复安装），通过 `managed.json` 登记表统一管理
- **管理页解释器表格新增「用户 Path」状态列**，一眼可见哪些解释器已加入环境变量

### 修复的问题

- 修复「管理」页安装 Python 后，**解释器页面刷新不显示新解释器**的问题（扫描器此前只有六大渠道，均不覆盖托管目录；现新增托管解释器扫描渠道）

### 其他改动

- 测试增至 64 个全部通过（新增登记表、自定义路径校验、用户 Path 真实注册表读写回环验证）
- 全流程真实验证：安装到自定义目录 + 勾选 Path → 扫描器即时发现 → 删除后 Path/登记/目录全部清理

### 安装

下载 `PyEnvInspector-1.1.2.msi` 双击安装（需要管理员权限）；从 v1.1.x 升级安装会自动换装，无需手动卸载。
