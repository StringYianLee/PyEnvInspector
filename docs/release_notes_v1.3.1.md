# PyEnv Inspector v1.3.1

两个影响使用体验的缺陷修复。

## 修复

- **打开软件后反复弹出 cmd 黑框**
  原因：GUI 程序自身没有控制台，但它启动的控制台子进程（解释器探测、`py` 启动器查询、
  `conda --version`、包元数据采集、pip/conda/venv 操作）在 Windows 上会被分配新的控制台窗口，
  扫描多个解释器时就会不停闪出黑框。
  修复：新增统一的子进程启动参数（`CREATE_NO_WINDOW` + `STARTF_USESHOWWINDOW/SW_HIDE`，
  POSIX 下独立会话），并应用到**全部**子进程调用点。现在启动与扫描全程无控制台窗口。

- **诊断页选择目标解释器后闪退/卡死**
  原因：填充目标解释器下拉时，恢复选中项发生在信号解除阻塞之后，于是
  `setCurrentIndex → currentIndexChanged → 加载环境 → 刷新报告 → 再填充下拉` 形成无限递归，
  最终 RecursionError 崩溃或界面卡死。
  修复：① 恢复选中项在信号阻塞期间完成；② 增加"程序化填充"标志，非用户切换不触发加载；
  ③ 主窗口对同一环境的诊断加载加重入保护；④ 刷新报告时不再把下拉选择回写成当前快照，
  保留用户在诊断页的选择。

## 验证

- 新增回归测试：子进程参数断言（探测 / conda 版本探测）、下拉填充零信号、连续切换 3 次
  目标解释器不递归且每次恰好一次信号、重入标记正常释放。
- 全量 **115 个测试通过**。

## 安装

下载 `PyEnvInspector-1.3.1.msi` 双击安装（需要管理员权限），从 1.3.0 / 1.2.x 升级自动换装。
